# LINEAR RENDER

Small lightweight OpenGL C11 Render hobby project using CGLM, GLAD, and GLFW.

Built from the ground up to understand the graphics pipeline.

## CURRENT FEATURES

- **Window Management**: Abstracted GLFW wrapper with `lr_window_t`.

- **Shader System**: Custom GLSL loader, compiler, and error-checking.

- **Vendored Deps**: Integrated GLFW (Source), GLAD, and CGLM.

## BUILD REQUIREMENTS

- CMake (3.10+)

- A C compiler (GCC/MinGW or Clang)

- OpenGL 3.3+ drivers
